# RPCRad

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md)

Локальный настольный инструмент отладки gRPC на Rust, GPUI и GPUI-KIT 0.8. Реальные запросы отправляются через встроенный grpcurl 1.9.3. Интерфейс нативный, без WebView.

## Установка и обновление

Скачайте пакет для своей системы и архитектуры со страницы [GitHub Releases](https://github.com/eyotang/RPCRad/releases/latest).

| Система | Архитектура | Пакет |
| --- | --- | --- |
| macOS 15+ | Apple Silicon / Intel | Отдельные `.dmg` |
| Windows 10/11 | x64 | Установщик `-setup.exe` или переносимый `.zip` |
| Ubuntu 24.04+ | x64 | `.deb` или переносимый `.tar.gz` |
| Omarchy / Arch Linux | x64 | `.pkg.tar.zst`, Wayland и X11 |

В пакеты входят grpcurl, примеры Proto и лицензии зависимостей. Для запуска не нужны Rust и Go. В Linux необходимы рабочий драйвер Vulkan и портал рабочего стола; для китайского, японского и корейского текста нужны соответствующие шрифты, например `noto-fonts-cjk`. Пакеты для Windows/Linux ARM64 пока не предоставляются.

В Ubuntu используйте `sudo apt install ./rpcrad_VERSION_amd64.deb`, в Arch — `sudo pacman -U ./rpcrad-VERSION-1-x86_64.pkg.tar.zst`, заменив VERSION на версию скачанного файла. Переносимые пакеты нужно распаковывать целиком: исполняемый файл, grpcurl и resources должны оставаться вместе. Подробности — в [руководстве по установке (на китайском)](docs/INSTALL.md).

В macOS откройте системное меню **RPCRad → О RPCRad / Проверить обновления**. В Windows/Linux используйте меню **RPCRad** в верхней части окна. Проверка также выполняется при запуске через GitHub Releases, `latest.json` и SHA-256. Новый пакет скачивается и устанавливается пользователем; рабочая область сохраняется. Скрытой замены приложения в фоне нет.

Пакеты macOS пока не имеют подписи Developer ID и нотариального заверения Apple; установщики Windows не подписаны Authenticode. Если карантин macOS мешает запуску, сначала убедитесь, что файл получен из официального репозитория и его SHA-256 совпадает. Только при необходимости выполните:

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

При другом расположении приложения замените путь. Это необязательная мера устранения проблемы, а не команда обновления. Приложение никогда не выполняет её автоматически.

## Языки интерфейса

В **RPCRad → Настройки… → Язык** доступны **简体中文, English, 日本語, 한국어, Français, Deutsch и Русский**. Язык меняется сразу и сохраняется после перезапуска. Для новых и старых рабочих областей без сохранённой настройки используется упрощённый китайский. Можно запустить приложение с `--language=ru`; доступны коды `zh-CN`, `en`, `ja`, `ko`, `fr`, `de`, `ru`.

Настройки открываются в отдельном окне с темами **Как в системе (по умолчанию), Светлая и Тёмная**. Изменения применяются сразу и сохраняются; системный режим следует изменениям оформления ОС. Проверка обновлений и сведения о приложении также используют отдельные окна. Повторное открытие выводит существующее окно вперёд, не заменяя экран запроса. Настройки: **⌘ ,** в macOS или **Ctrl+,** в Windows/Linux. Закрытие вспомогательного окна: **Esc** или **⌘/Ctrl+W**.

Переводятся сообщения приложения и описания встроенных плагинов. Пользовательские имена, значения переменных, данные запросов и ответов, а также существующие снимки вызовов не изменяются. Сообщения сервера и сторонние плагины без переводов автоматически не переводятся.

## Возможности и первый запрос

Импортируйте Proto или воспользуйтесь рефлексией сервера, выберите метод, введите адрес и отправьте запрос. В macOS отправка выполняется через **⌘ Enter**, в Windows/Linux — **Ctrl+Enter**. **⌘/Ctrl+K** открывает поиск, **⌘/Ctrl+S** сохраняет рабочую область. Ширина боковой панели и столбцов редактора регулируется.

- Дерево сервисов и методов, поиск, избранное, вкладки и сохранённые черновики.
- Нативный JSON-редактор с подсветкой, форматированием и примерами из Proto.
- Unary и серверные потоки, отмена, тайм-ауты, статус и время выполнения.
- Метаданные, токены Bearer и TLS с доверенными центрами сертификации системы.
- Окружения, общие переменные и плагины подписи заголовков.
- Тело ответа, Headers, Trailers, копирование и до 50 вызовов в истории сеанса.

Откройте запись истории, чтобы увидеть фактическое тело, настройки подключения, исходные заголовки и итоговые метаданные, переданные grpcurl. Обычные заголовки видны полностью; секретные поля раскрываются отдельно. Копируется текущее отображаемое содержимое. Корзина очищает историю, не прерывая активный вызов. **Загрузить запрос** восстанавливает адрес, тело и подключение; заголовки используют текущие настройки, а плагины выполняются заново при отправке.

Ошибка или отмена до отправки явно помечается как неотправленный запрос. Снимок не включает автоматически добавленные заголовки HTTP/2 и не доказывает, что сервер получил данные. Клиентские и двунаправленные потоки, собственные CA/mTLS и полное управление корнями импорта Proto пока не поддерживаются. Отображение ответа ограничено 8 MiB.

## Окружения и переменные

Меню окружений и **Переменные** позволяют создавать, переименовывать и удалять окружения, редактировать значения. Активное окружение заменяет одноимённые общие переменные. Если окружение не выбрано, используются только общие значения.

Примеры: `{{endpoint}}` в адресе, `{{appid}}` в AppID плагина, `{{secret}}` в Secret. Тело запроса:

```text
{
  "user_id": "{{user_id}}",
  "include_profile": {{include_profile}}
}
```

Ссылки в кавычках экранируются как строки JSON. Без кавычек значение должно быть корректным JSON: числом, логическим значением, объектом или массивом. Значения метаданных должны быть строками. Поддерживаются вложенные ссылки, например `{{host}}:{{port}}`. Неопределённые переменные, повторяющиеся имена и циклические ссылки блокируют отправку. Имена начинаются с буквы латинского алфавита или подчёркивания и могут содержать цифры, точки и дефисы.

Обычные значения сохраняются. Секретные переменные, Secret открытым текстом, авторизация, метаданные и история хранятся только в сеансе. Полная ссылка `{{secret}}` сохраняется, но секретное значение после перезапуска нужно ввести заново. Если секретная переменная использована в теле или заголовке, она отправляется и появляется в снимке этого сеанса. Черновики на диске сохраняют шаблоны без подстановки значений.

## Плагины заголовков

Выберите **MD5 · AppID + Метка времени**, введите AppID и Secret, затем включите плагин. При каждой отправке текущая Unix-метка в миллисекундах записывается в `ts`, а `sign` вычисляется как строчное шестнадцатеричное значение `MD5(secret + appid + ts + secret)`. Отправляются заголовки `appid`, `ts` и `sign`; подпись и метка используют один момент времени. Имена заголовков, единица времени и регистр настраиваются.

Включены примеры HMAC-SHA256 и AES-256-GCM. На один вызов запускается один выбранный плагин; цепочки и привязка к отдельным методам пока недоступны. Смена плагина очищает Secret, сохраняя обычные настройки каждого плагина. Предпросмотр — только снимок; при отправке всё вычисляется заново. Фактически отправленные значения проверяйте в новой записи истории. См. [разработку плагинов (на китайском)](plugins/README.md) для Rhai и полей перевода.

## Разработка и проверка

Нужны Rust stable, Go, Python 3.11+ и нативные средства сборки системы. Версия Go закреплена в `.go-version`.

```sh
python tools/setup.py
cargo run --locked
cargo test --locked
cargo clippy --all-targets --all-features --locked -- -D warnings
python -m unittest discover -s tools/tests
```

`tools/bin/rpcrad-demo` запускает пример сервера на `127.0.0.1:50051`. Попробуйте GetUser, WatchUsers или `user_id = missing` для ответа NotFound. В macOS `Launch RPCRad.command` запускает пример и открывает приложение. Учётная запись и облачный сервис не нужны. При запуске проверяется версия на GitHub без передачи содержимого запросов.

Выпуски проверяются на обеих архитектурах Mac, Windows, Ubuntu и Arch/Wayland. Описание каждого выпуска содержит китайский и английский разделы и инструкции xattr. См. [процесс выпуска (на китайском)](docs/RELEASING.md) и [AGENTS.md](AGENTS.md). Основные файлы: `src/ui.rs`, `src/rpc.rs`, `locales/`, `examples/protos/`, `tools/demo/`. Источники идей дизайна: BloomRPC, Kreya, Yaak. Лицензии зависимостей определяются соответствующими исходными проектами.
