# RPCRad 0.5.0

## 中文

新增日本語、한국어、Français、Deutsch、Русский，连同简体中文和 English，共支持七种界面语言。顶部语言菜单可即时切换，选择随工作区保存，重启后自动恢复。

- 菜单、请求编辑、认证、历史详情、环境与变量管理、更新提示、常见错误及内置插件文案同步支持七种语言。
- 输入框右键菜单及密码显示/隐藏提示补齐本地化，发送按钮适应较长译文。
- README 提供中文、英文、日文、韩文、法文、德文、俄文版本，并可相互切换。
- 统一翻译目录，构建时检查翻译完整性和格式参数，防止缺译或参数丢失；发布流程强制检查中英文说明和 macOS xattr 命令。
- 切换语言保留请求草稿、Metadata、认证、变量和插件设置。请求/响应数据、变量值、用户命名与已有调用快照保留原样；未提供翻译的第三方插件文案不会自动翻译。
- 启动参数支持 `--language=zh-CN`、`--language=en`、`--language=ja`、`--language=ko`、`--language=fr`、`--language=de`、`--language=ru`。

### 下载、升级与验证范围

在应用菜单中选择“检查更新”，下载对应平台安装包，退出旧版后安装。个人工作区配置保留；敏感值与调用历史仍仅保存在当前会话。每个安装包均附有 SHA-256 校验文件。

- macOS 15+：选择 Apple Silicon 或 Intel DMG，替换 Applications 中的 RPCRad。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.5.0_amd64.deb`；也提供完整目录的 tar.gz 包。
- Omarchy / Arch Linux x64：下载 `rpcrad-0.5.0-1-x86_64.pkg.tar.zst`，执行 `sudo pacman -U ./rpcrad-0.5.0-1-x86_64.pkg.tar.zst`。

发布检查覆盖 Apple Silicon、Intel Mac、Windows、Ubuntu/X11 及 Arch/Weston Wayland，包括安装包运行、真实 gRPC 请求与毫秒时间戳签名，以及七种语言的原生窗口绘制、切换时数据保留和重启恢复。Omarchy 的实际 Hyprland 桌面、不同显卡和缩放仍需设备验证；Linux 需 Vulkan 驱动及正常的桌面 portal。Windows / Linux ARM64 暂不支持。

### macOS 打开提示

Mac 包仍未 Developer ID 签名、公证；Windows 安装器暂未 Authenticode 签名。如果 macOS 隔离导致无法打开，先确认文件来自本官方仓库且 SHA-256 一致，再由用户按需执行；路径不同请替换为实际安装路径。这不是更新步骤，程序和发布脚本不会自动执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

详见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.5.0/docs/INSTALL.md)。

## English

Adds Japanese, Korean, French, German and Russian alongside Simplified Chinese and English, bringing the interface to seven languages. Switch immediately using the language menu at the top. Your choice is saved with the workspace and restored after restart.

- Localizes menus, request editing, authentication, history details, environments and variables, update messages, common errors and built-in plugin text in all seven languages.
- Localizes input context menus and password visibility hints, and lets the Send button accommodate longer translations.
- Provides Chinese, English, Japanese, Korean, French, German and Russian READMEs with links between them.
- Centralizes translation catalogs and checks completeness and format arguments during builds. Release checks require substantive Chinese and English notes and the macOS xattr command.
- Switching languages preserves request drafts, metadata, authentication, variables and plugin settings. Request/response data, variable values, user-defined names and existing call snapshots retain their original content. Untranslated third-party plugin text is not automatically translated.
- Supports `--language=zh-CN`, `--language=en`, `--language=ja`, `--language=ko`, `--language=fr`, `--language=de` and `--language=ru`.

### Download, upgrade and verification scope

Choose **Check for updates** in the application menu, download the package for your system, quit the old app and install. Your workspace configuration is preserved; sensitive values and call history remain session-only. Every package includes a SHA-256 file.

- macOS 15+: choose the Apple Silicon or Intel DMG and replace RPCRad in Applications.
- Windows 10/11 x64: run the setup.exe installer or extract the entire portable ZIP.
- Ubuntu 24.04+ x64: `sudo apt install ./rpcrad_0.5.0_amd64.deb`. A complete portable tar.gz package is also available.
- Omarchy / Arch Linux x64: download `rpcrad-0.5.0-1-x86_64.pkg.tar.zst` and run `sudo pacman -U ./rpcrad-0.5.0-1-x86_64.pkg.tar.zst`.

Release checks cover Apple Silicon, Intel Mac, Windows, Ubuntu/X11 and Arch/Weston Wayland: running installed packages, real gRPC calls and millisecond timestamp signing, plus native window rendering in all seven languages, switching without changing data and restoring the language after restart. Real Omarchy/Hyprland desktops, different GPUs and scaling settings still require device testing. Linux requires a working Vulkan driver and desktop portal. Windows and Linux ARM64 are not supported yet.

### Opening on macOS

macOS packages currently lack Developer ID signing and notarization; Windows installers lack Authenticode signing. If macOS quarantine prevents launching, first confirm the download came from this official repository and its SHA-256 matches. Only then, if needed, run the following. Replace the path if installed elsewhere. This is not an update step; the application and release scripts never execute it automatically.

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

See the [installation guide](https://github.com/eyotang/RPCRad/blob/v0.5.0/docs/INSTALL.md).
