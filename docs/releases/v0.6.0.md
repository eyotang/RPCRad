# RPCRad 0.6.0

## 中文

应用设置、检查更新和关于改为独立原生窗口，增加主题选择，调整语言切换入口和控件布局。

- 在 **RPCRad → 设置… → 语言** 切换七种界面语言；主窗口顶部不再显示语言选择器。选择器固定为紧凑的 180px 宽度、左侧对齐，不再铺满整行。
- 设置、检查更新和关于各自打开独立窗口，不再替换主窗口的请求页面。重复打开会唤起已有窗口，关闭后可以重新打开。
- 设置提供 **跟随系统 / 亮色 / 暗色**；立即应用并自动保存，重启后恢复。新工作区和未保存主题的旧工作区默认跟随系统，系统外观变化时同步更新。
- 暗色主题覆盖主界面、请求与响应编辑器、历史、插件、环境管理和辅助窗口，保持绿色操作按钮与清晰的文字对比。
- macOS 使用 **⌘ ,**，Windows/Linux 使用 **Ctrl+,** 打开设置；**Esc** 或 **⌘/Ctrl+W** 关闭辅助窗口。请求页原“设置”标签改为“连接”，保留每个请求的 TLS 和超时配置。
- 调整较长译文的按钮布局；七种语言的 README 同步说明新的菜单入口、独立窗口与主题选项。
- 切换语言或主题保留请求草稿、Metadata、认证、变量和插件配置，不改写请求/响应内容。

### 下载、升级与验证范围

在应用菜单中选择“检查更新”，下载对应平台安装包，退出旧版后安装。个人工作区配置保留；敏感值与调用历史仍仅保存在当前会话。每个安装包均附有 SHA-256 校验文件。

- macOS 15+：选择 Apple Silicon 或 Intel DMG，替换 Applications 中的 RPCRad。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.6.0_amd64.deb`；也提供完整目录的 tar.gz 包。
- Omarchy / Arch Linux x64：下载 `rpcrad-0.6.0-1-x86_64.pkg.tar.zst`，执行 `sudo pacman -U ./rpcrad-0.6.0-1-x86_64.pkg.tar.zst`。

发布检查覆盖 Apple Silicon、Intel Mac、Windows、Ubuntu/X11 及 Arch/Weston Wayland，包括安装包运行、真实 gRPC 请求与毫秒时间戳签名，以及七种语言的原生窗口绘制、语言和主题切换时数据保留、重启恢复，以及独立窗口的打开、复用与关闭重开。Omarchy 的实际 Hyprland 桌面、不同显卡和缩放仍需设备验证；Linux 需 Vulkan 驱动及正常的桌面 portal。Windows / Linux ARM64 暂不支持。

### macOS 打开提示

Mac 包仍未 Developer ID 签名、公证；Windows 安装器暂未 Authenticode 签名。如果 macOS 隔离导致无法打开，先确认文件来自本官方仓库且 SHA-256 一致，再由用户按需执行；路径不同请替换为实际安装路径。这不是更新步骤，程序和发布脚本不会自动执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

详见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.6.0/docs/INSTALL.md)。

## English

Moves application settings, update checks and About into separate native windows, adds theme selection and refines the language control and its location.

- Switch among seven interface languages in **RPCRad → Settings… → Language**. The main toolbar no longer contains a language selector. Its settings control is left-aligned with a compact 180px width instead of stretching across the window.
- Settings, Check for updates and About each open a separate window without replacing the request view. Opening one again brings the existing window forward; closed windows can be reopened.
- Choose **Follow system / Light / Dark** in Settings. Changes apply immediately, are saved automatically and restore after restart. New workspaces and older workspaces without a theme preference follow the system by default and respond to system appearance changes.
- Dark mode covers the main interface, request and response editors, history, plugins, environment management and utility windows, retaining green action buttons and readable text contrast.
- Open Settings with **⌘ ,** on macOS or **Ctrl+,** on Windows/Linux. Close utility windows with **Esc** or **⌘/Ctrl+W**. The request page's former Settings tab is now named Connection and retains request-specific TLS and timeout options.
- Adjusts button layout for longer translations. READMEs in all seven languages document the new menu entry, separate windows and theme choices.
- Switching language or theme preserves request drafts, metadata, authentication, variables and plugin configuration without rewriting request/response content.

### Download, upgrade and verification scope

Choose **Check for updates** in the application menu, download the package for your system, quit the old app and install. Your workspace configuration is preserved; sensitive values and call history remain session-only. Every package includes a SHA-256 file.

- macOS 15+: choose the Apple Silicon or Intel DMG and replace RPCRad in Applications.
- Windows 10/11 x64: run the setup.exe installer or extract the entire portable ZIP.
- Ubuntu 24.04+ x64: `sudo apt install ./rpcrad_0.6.0_amd64.deb`. A complete portable tar.gz package is also available.
- Omarchy / Arch Linux x64: download `rpcrad-0.6.0-1-x86_64.pkg.tar.zst` and run `sudo pacman -U ./rpcrad-0.6.0-1-x86_64.pkg.tar.zst`.

Release checks cover Apple Silicon, Intel Mac, Windows, Ubuntu/X11 and Arch/Weston Wayland: running installed packages, real gRPC calls and millisecond timestamp signing, plus native window rendering in all seven languages, language/theme switching without changing data, preference restoration after restart, and opening, reusing, closing and reopening separate windows. Real Omarchy/Hyprland desktops, different GPUs and scaling settings still require device testing. Linux requires a working Vulkan driver and desktop portal. Windows and Linux ARM64 are not supported yet.

### Opening on macOS

macOS packages currently lack Developer ID signing and notarization; Windows installers lack Authenticode signing. If macOS quarantine prevents launching, first confirm the download came from this official repository and its SHA-256 matches. Only then, if needed, run the following. Replace the path if installed elsewhere. This is not an update step; the application and release scripts never execute it automatically.

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

See the [installation guide](https://github.com/eyotang/RPCRad/blob/v0.6.0/docs/INSTALL.md).
