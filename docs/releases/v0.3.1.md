# RPCRad 0.3.1

完善 Omarchy / Arch Linux 的安装入口与发布标识。

- 发布页明确标注 **Omarchy / Arch Linux x64** 安装包，后续版本自动保留该标识。
- README 与安装说明提供直接下载入口和 pacman 安装命令。
- 保留 0.3.0 的环境变量、插件签名和调用历史功能。
- 所有平台重新构建，并在安装、请求签名与原生界面检查通过后统一发布更新清单。

## Omarchy / Arch Linux x64

[下载安装包](https://github.com/eyotang/RPCRad/releases/download/v0.3.1/rpcrad-0.3.1-1-x86_64.pkg.tar.zst) · [SHA-256 校验文件](https://github.com/eyotang/RPCRad/releases/download/v0.3.1/rpcrad-0.3.1-1-x86_64.pkg.tar.zst.sha256)

在下载目录执行：

```sh
sudo pacman -U ./rpcrad-0.3.1-1-x86_64.pkg.tar.zst
```

安装后从应用启动器打开 RPCRad，或运行 `rpcrad`。升级使用同样命令，保留个人工作区配置。系统需有适合显卡的 Vulkan 驱动及正常的桌面 portal。CI 验证 Arch + Weston Wayland；尚未在真实 Omarchy/Hyprland 桌面上人工验证。

## 其他平台与更新

- macOS 15+：选择 Apple Silicon 或 Intel DMG，退出旧版后替换 Applications 中的应用。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.3.1_amd64.deb`。

菜单“检查更新”可以发现新版并打开官方下载页。敏感值与调用历史仅保存在当前会话。

Mac 包仍未 Developer ID 签名、公证。确认来自本仓库且 SHA-256 一致后，若被系统隔离，可针对应用执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

Windows 安装器暂未 Authenticode 签名。各包均附带 SHA-256 校验文件。详见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.3.1/docs/INSTALL.md)。
