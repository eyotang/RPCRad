# RPCRad 0.1.3

- macOS 顶部 RPCRad 菜单新增「关于 RPCRad…」和「检查更新…」。
- 主动检查更新会直接打开版本信息页，显示检查状态、新版说明及下载按钮；网络失败可重新检查。
- 关于页显示应用图标、当前版本和项目主页，关闭后返回之前的请求或历史详情。
- 保留设置页的检查入口、启动时自动检查、逐字段敏感值显示以及垃圾桶清理历史。

**从 0.1.1 / 0.1.2 升级：** 在旧版的「设置」页底部点击检查更新，或从本页下载 DMG。退出旧应用，把 RPCRad 拖入 Applications 替换，再打开新版。新版可以直接从顶部菜单检查更新。

需要 macOS 14+、Apple Silicon。安装包包含 grpcurl 和示例 Proto，工作区配置保存在用户数据目录；Secret 和调用历史仅保留在当前会话。此包采用 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证。

如果下载后被 macOS 隔离，在确认来自本仓库且 SHA-256 校验一致后，可只对已安装的 RPCRad 执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

安装在其他目录时替换为实际路径；正常能打开时无需运行。

`latest.json` 为更新清单，`.dmg.sha256` 用于校验安装包。沿用 Metra 的 macOS 方式：检查新版后打开对应下载页，由用户替换应用。
