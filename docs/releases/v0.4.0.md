# RPCRad 0.4.0

新增简体中文与英文界面，可在顶部 **简体中文 / English** 下拉框即时切换，无需重启。

- 语言选择随工作区保存；首次启动与旧工作区默认使用简体中文。
- 菜单、请求编辑、认证与连接设置、历史详情、环境管理、更新提示及常见错误均支持中英文。
- 内置 MD5、HMAC-SHA256、AES-256-GCM 插件补齐英文名称、说明、字段与错误提示。
- 本地插件可选提供 `name_en`、`description_en`、`label_en`；缺省时保留原文。脚本可使用 `ui_text(中文, 英文)` 输出本地化提示。
- 切换语言保留正在编辑的请求、Metadata、认证和插件配置。请求/响应内容、变量值、环境名称与已有调用快照保持原样。
- 启动参数 `--language=en` 或 `--language=zh-CN` 可覆盖保存的选择。
- 各平台增加中英文窗口、切换时内容保留与重启后语言恢复检查；继续验证真实 gRPC 请求与毫秒时间戳签名。

服务端返回内容和未提供翻译的第三方插件文案不会自动翻译。使用 `ui_text` 的新脚本需要 0.4.0 或更新版本宿主。

## Omarchy / Arch Linux x64

[下载安装包](https://github.com/eyotang/RPCRad/releases/download/v0.4.0/rpcrad-0.4.0-1-x86_64.pkg.tar.zst) · [SHA-256 校验文件](https://github.com/eyotang/RPCRad/releases/download/v0.4.0/rpcrad-0.4.0-1-x86_64.pkg.tar.zst.sha256)

在下载目录执行：

```sh
sudo pacman -U ./rpcrad-0.4.0-1-x86_64.pkg.tar.zst
```

安装后从应用启动器打开 RPCRad，或运行 `rpcrad`。升级使用同样命令，保留个人工作区配置。系统需有适合显卡的 Vulkan 驱动及正常的桌面 portal。CI 验证 Arch + Weston Wayland；尚未在真实 Omarchy/Hyprland 桌面上人工验证。

## 其他平台与更新

- macOS 15+：选择 Apple Silicon 或 Intel DMG，退出旧版后替换 Applications 中的应用。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.4.0_amd64.deb`。

菜单“检查更新”可以发现新版并打开官方下载页。敏感值与调用历史仅保存在当前会话。

Mac 包仍未 Developer ID 签名、公证。确认来自本仓库且 SHA-256 一致后，若被系统隔离，可针对应用执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

Windows 安装器暂未 Authenticode 签名。各包均附带 SHA-256 校验文件。详见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.4.0/docs/INSTALL.md)。
