# RPCRad 0.3.0

新增环境与变量管理，支持在请求和签名插件中使用同一套变量。

- 右上角切换环境，“变量”入口管理全局变量和各环境变量，支持新建、重命名、删除与自动保存。
- 使用 `{{变量名}}` 引用；当前环境覆盖同名全局变量。支持变量之间的引用，缺失、重复或循环引用会阻止发送并提示原因。
- 地址、Metadata、Bearer Token、插件参数和 Secret 均支持变量；先解析变量，再计算签名。
- 包体字符串使用 `"{{user_id}}"`，数字、布尔值、对象和数组可直接使用 `{{变量名}}`。字符串内容自动进行 JSON 转义。
- 普通变量完整显示并保存；敏感变量独立显示/隐藏，值只保留在会话中。Secret 框中的变量引用会保存，明文 Secret 不保存。
- 调用详情记录当次环境名称、解析后的地址和实际包体，之后切换环境不会改变历史快照。请求草稿仍保留变量模板。

例如：环境中设置 appid、user_id、secret，插件 AppID 填 `{{appid}}`，Secret 填 `{{secret}}`，包体使用 `{"user_id":"{{user_id}}"}`。MD5 插件仍在每次发送时生成当前毫秒时间戳。

## 安装和更新

- macOS 15+：选择 Apple Silicon 或 Intel DMG，退出旧版后替换 Applications 中的应用。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.3.0_amd64.deb`。
- Omarchy / Arch x64：[下载 pacman 安装包](https://github.com/eyotang/RPCRad/releases/download/v0.3.0/rpcrad-0.3.0-1-x86_64.pkg.tar.zst)，安装命令 `sudo pacman -U ./rpcrad-0.3.0-1-x86_64.pkg.tar.zst`。支持原生 Wayland 与 X11；CI 的 Arch/Weston 检查不能替代所有 Hyprland 显卡组合的人工测试。

菜单“检查更新”可发现新版，更新后保留原工作区。敏感值和调用历史仅保存在当前会话；若在包体或业务头部中主动引用敏感变量，它会成为实际请求内容并显示在会话快照中。

Mac 包仍未 Developer ID 签名、公证。确认来自本仓库且 SHA-256 一致后，若被系统隔离，可针对应用执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

Windows 安装器暂未 Authenticode 签名。各包均附带 SHA-256 校验文件。详细步骤见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.3.0/docs/INSTALL.md)。
