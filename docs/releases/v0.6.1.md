# RPCRad 0.6.1

## 中文

增加系统语言自动检测，并保留已有的手动语言选择。

- 在 **RPCRad → 设置… → 语言** 中新增 **自动检测（跟随系统）**，作为新工作区和未保存语言选择的旧工作区的默认值。
- 启动或选择自动检测时，按系统首选语言顺序匹配七种支持语言；兼容 `ja-JP`、`fr-CA`、`de_DE.UTF-8` 等地区与格式差异。中文变体使用简体中文，没有匹配或读取失败时回退到英文。
- macOS、Windows 使用系统首选界面语言，Linux（含 Ubuntu、Omarchy/Arch）读取会话的语言环境。系统语言设置改变后，重新启动应用以重新检测。
- 自动模式显示当前识别的语言，选择器继续保持 180px 紧凑宽度。
- 自动模式与手动选择分别保存，即使两者当前显示同一种语言也能正确切换。已有手动选择不会被系统设置覆盖，重启后保留自动或手动模式。
- 支持 `--language=auto`；原有七种手动语言启动参数保持兼容。切换语言不修改请求、认证、变量和插件配置。
- 七种语言的界面文案和 README 同步更新；增加地区匹配、回退、旧配置兼容、自动/手动切换和重启恢复验证。

### 下载、升级与验证范围

在应用菜单中选择“检查更新”，下载对应平台安装包，退出旧版后安装。个人工作区配置保留；敏感值与调用历史仍仅保存在当前会话。每个安装包均附有 SHA-256 校验文件。

- macOS 15+：选择 Apple Silicon 或 Intel DMG，替换 Applications 中的 RPCRad。
- Windows 10/11 x64：运行 setup.exe，或完整解压便携 ZIP。
- Ubuntu 24.04+ x64：`sudo apt install ./rpcrad_0.6.1_amd64.deb`；也提供完整目录的 tar.gz 包。
- Omarchy / Arch Linux x64：下载 `rpcrad-0.6.1-1-x86_64.pkg.tar.zst`，执行 `sudo pacman -U ./rpcrad-0.6.1-1-x86_64.pkg.tar.zst`。

发布检查覆盖 Apple Silicon、Intel Mac、Windows、Ubuntu/X11 及 Arch/Weston Wayland，包括安装包运行、真实 gRPC 请求与毫秒时间戳签名，以及七种语言及自动模式的原生窗口绘制、语言和主题切换时数据保留、自动/手动语言与主题的重启恢复，以及独立窗口的打开、复用与关闭重开。Omarchy 的实际 Hyprland 桌面、不同显卡和缩放仍需设备验证；Linux 需 Vulkan 驱动及正常的桌面 portal。Windows / Linux ARM64 暂不支持。

### macOS 打开提示

Mac 包仍未 Developer ID 签名、公证；Windows 安装器暂未 Authenticode 签名。如果 macOS 隔离导致无法打开，先确认文件来自本官方仓库且 SHA-256 一致，再由用户按需执行；路径不同请替换为实际安装路径。这不是更新步骤，程序和发布脚本不会自动执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

详见[安装说明](https://github.com/eyotang/RPCRad/blob/v0.6.1/docs/INSTALL.md)。

## English

Adds automatic system language detection while preserving existing manual language choices.

- Adds **Automatic (system)** to **RPCRad → Settings… → Language**, the default for new workspaces and older workspaces without a saved language preference.
- On startup or when Automatic is selected, chooses the first supported language in the system's preference order. Handles regional and locale formats such as `ja-JP`, `fr-CA` and `de_DE.UTF-8`. Chinese variants use Simplified Chinese; no match or failed detection falls back to English.
- macOS and Windows use preferred system UI languages. Linux, including Ubuntu and Omarchy/Arch, reads the session's locale environment. Restart the application after changing system language settings to detect them again.
- Automatic mode displays the resolved language and keeps the compact 180px selector.
- Automatic and manual choices are saved separately, even when they currently resolve to the same language. Existing manual choices are not overridden by the system, and the chosen mode is restored after restart.
- Adds `--language=auto` while retaining all seven manual language arguments. Switching languages does not modify requests, authentication, variables or plugin configuration.
- Updates interface text and READMEs in all seven languages, with checks for regional matching, fallback, older preferences, switching modes and restoring them after restart.

### Download, upgrade and verification scope

Choose **Check for updates** in the application menu, download the package for your system, quit the old app and install. Your workspace configuration is preserved; sensitive values and call history remain session-only. Every package includes a SHA-256 file.

- macOS 15+: choose the Apple Silicon or Intel DMG and replace RPCRad in Applications.
- Windows 10/11 x64: run the setup.exe installer or extract the entire portable ZIP.
- Ubuntu 24.04+ x64: `sudo apt install ./rpcrad_0.6.1_amd64.deb`. A complete portable tar.gz package is also available.
- Omarchy / Arch Linux x64: download `rpcrad-0.6.1-1-x86_64.pkg.tar.zst` and run `sudo pacman -U ./rpcrad-0.6.1-1-x86_64.pkg.tar.zst`.

Release checks cover Apple Silicon, Intel Mac, Windows, Ubuntu/X11 and Arch/Weston Wayland: running installed packages, real gRPC calls and millisecond timestamp signing, plus native window rendering in all seven languages and Automatic mode, language/theme switching without changing data, automatic/manual language and theme preference restoration after restart, and opening, reusing, closing and reopening separate windows. Real Omarchy/Hyprland desktops, different GPUs and scaling settings still require device testing. Linux requires a working Vulkan driver and desktop portal. Windows and Linux ARM64 are not supported yet.

### Opening on macOS

macOS packages currently lack Developer ID signing and notarization; Windows installers lack Authenticode signing. If macOS quarantine prevents launching, first confirm the download came from this official repository and its SHA-256 matches. Only then, if needed, run the following. Replace the path if installed elsewhere. This is not an update step; the application and release scripts never execute it automatically.

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

See the [installation guide](https://github.com/eyotang/RPCRad/blob/v0.6.1/docs/INSTALL.md).
