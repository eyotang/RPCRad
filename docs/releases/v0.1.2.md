# RPCRad 0.1.2

macOS Apple Silicon 版本，需要 macOS 14 或更新版本。

- 新增历史清理按钮（垃圾桶图标）：左侧历史和底部调用记录均可一键清空，不弹确认框；正在进行的请求继续执行。清空后自动关闭旧记录详情，当前请求配置保留。

- 原生 GPUI / GPUI-KIT 界面，支持 Proto 导入、服务反射、Unary 与服务端流调用。
- Metadata、Bearer Token、TLS、超时、取消和请求草稿。
- 本地请求头插件：MD5(secret + appid + ts + secret)，默认当前毫秒时间戳；支持自定义头名称，附带 HMAC-SHA256 与 AES-256-GCM 示例。
- 点击调用记录查看插件处理前与最终请求头、请求体、响应 Headers / Trailers，普通头部默认完整显示和复制，Secret、密码、Token 等敏感字段支持逐项显示/隐藏；插件 Secret 输入框支持独立显示/隐藏。未发送的记录直接显示失败原因；Secret 不落盘。
- 沿用 Metra 的 macOS 更新方案：启动时检查 GitHub latest.json，发现新版本后打开对应下载页。
- 工作区保存在用户数据目录，替换应用后保留配置。从原项目源码构建的新版首次启动时可读取该项目旧工作区；认证信息仍仅保留在当前会话。

下载 DMG，将 RPCRad 拖入 Applications。安装包包含 grpcurl 和示例 Proto，无需安装 Rust 或 Go。示例服务仅供源码开发环境使用；实际调试请连接自己的 gRPC 服务。

此版本仅提供 Apple Silicon 安装包，使用本地 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证。Windows、Linux 和 Intel 安装包尚未发布；客户端流、双向流与 mTLS 尚未开放。

`latest.json` 是更新清单；`.dmg.sha256` 用于校验安装包完整性。macOS 更新通过下载并替换应用完成，不会静默覆盖正在运行的程序。
