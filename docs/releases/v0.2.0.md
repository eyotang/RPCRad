# RPCRad 0.2.0

跨平台版本，继续使用 GPUI / GPUI-KIT 原生界面。

- macOS 15+：Apple Silicon 和 Intel 两种 DMG。
- Windows 10/11 x64：安装器 EXE 和便携 ZIP，内嵌应用图标，调用 grpcurl 不弹命令窗口。
- Ubuntu 24.04+ x64：DEB 安装包和便携 tar.gz。
- Omarchy / Arch x64：pacman 的 pkg.tar.zst 包；支持原生 Wayland 与 X11。
- Windows/Linux 窗口顶部增加 RPCRad 菜单，包含关于和检查更新；快捷键使用 Ctrl。
- 随包资源按安装位置查找，所有平台都内置 grpcurl 和示例 Proto，升级保留工作区配置。
- 统一更新清单只有在所有平台包和 SHA-256 校验齐全后才发布。

## 安装

Mac：打开对应架构 DMG，拖入 Applications。Windows：运行 setup.exe；便携版完整解压后运行 RPCRad.exe。Ubuntu：`sudo apt install ./rpcrad_0.2.0_amd64.deb`。Omarchy / Arch：`sudo pacman -U ./rpcrad-0.2.0-1-x86_64.pkg.tar.zst`。

Mac 包仍未 Developer ID 签名、公证。确认下载来自本仓库且 SHA-256 一致后，若被系统隔离，可针对当前应用执行：

```sh
xattr -dr com.apple.quarantine /Applications/RPCRad.app
open /Applications/RPCRad.app
```

Windows 安装器暂未 Authenticode 签名。Linux 需要正常的 Vulkan 驱动、字体与桌面 portal；Arch/Wayland 的 CI 使用 Weston，不能替代对所有 Hyprland 显卡组合的人工验证。

详细步骤与依赖：[安装说明](https://github.com/eyotang/RPCRad/blob/v0.2.0/docs/INSTALL.md)。更新继续使用 GitHub Release + latest.json，点击下载后按系统安装，不静默替换正在运行的应用。Secret 和历史只保存在当前会话。
