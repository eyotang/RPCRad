Use case: ui-mockup
Create ONE high fidelity desktop application UI design screenshot for "RPCRad", a local gRPC debugging tool intended for Rust GPUI + GPUI-KIT. This is an actual application interface, NOT a marketing website, NOT a moodboard. Single landscape canvas 1600x1000-ish, straight-on, sharp typography, no perspective. The application fills the canvas, thin native rounded window corners, no surrounding device or large background margins.
Visual direction: exceptionally polished light native macOS developer tool. Quiet white and pale neutral gray surfaces, crisp hairline borders, dark graphite text, restrained emerald green accent for active methods and send action. Inspired by the practical simplicity of BloomRPC, clean workspace navigation of Kreya, and focused desktop feel of Yaak. Professional compact density with breathing room. SF Pro-like UI text, SF Mono-like JSON. 6px control corner radii, 28-34px controls, tiny consistent 1.5px stroke icons. NO purple, gradients, oversized headlines, dashboard metric cards, big shadows, decorative illustrations or website sections.

Section label "PROTO 文件" with count "3". File user.proto expanded, package user.v1 in faint caption, service UserService expanded. Four indented RPC rows "GetUser" selected with muted green rounded highlight, "ListUsers", "CreateUser", "WatchUsers"; each has a tiny method/stream icon and discrete type label such as "Unary" or "Stream". Next files order.proto and health.proto collapsed. Lower sidebar section "收藏" with one saved item "获取测试用户". Bottom sidebar small folder icon with "本地保存" and subtle green check.
4) Main workspace occupies remaining width. First a tab bar: selected "GetUser" with small green RPC icon and close icon; inactive "WatchUsers"; plus tab button.
